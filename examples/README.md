# 通用草稿模板 / Generic draft templates

这些模板不是作者的真实文章或项目。运行 `python3 blog/init_content.py` 后，它们被复制到被 Git 忽略的 publications 目录，已有文件不会覆盖。

These templates do not contain the author's real content. Run `python3 blog/init_content.py` to copy them into the Git-ignored publications library without overwriting existing files.
